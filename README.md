# 🎓 Student Score Prediction - AI & Machine Learning

An end-to-end Machine Learning project built during the **Codomax Digital Solutions AI & ML Internship**. This project utilizes Linear Regression to predict a student's exam score based on the number of hours spent studying.

---

## 📌 Project Overview

- **Objective:** Predict academic performance based on study duration.
- **Model:** Simple Linear Regression (Scikit-Learn)
- **Dataset:** Student Study Hours vs. Exam Scores
- **Metrics Evaluated:** MAE, MSE, RMSE, and $R^2$ Score
